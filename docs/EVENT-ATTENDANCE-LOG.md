## Recording rules

- Use the number of people who actually attended, not the number invited or registered.
- State whether a total is an exact count or a documented estimate.
- Keep personal information outside this repository.
- Record the source of every count and the person who verified it.
- Publish only reviewed aggregate totals on the website.
