# Vercel deployment and web analytics plan

## Public address

- Preferred Vercel project name: `cal-state-la-ecocar`.
- Expected Vercel address, subject to availability: `https://cal-state-la-ecocar.vercel.app`.
- Long-term institutional option: request `ecocar.calstatela.edu` from Cal State LA and connect it to the Vercel project.

## Ownership

- Use a continuing team-controlled Vercel account or team with faculty access.
- Do not make a graduating student's personal account the sole owner.
- Record who controls the Vercel account and who can view analytics before launch.

## Analytics

- Enable Vercel Web Analytics in the project dashboard after the project is created.
- Add the static-site tracking snippet generated by Vercel only after its unique script path is available.
- Verify page views on the production hostname after redeployment.
- Review traffic by route, referrer, device category, and date range.
- Export periodic summaries when the team needs evidence of traffic growth.
- Website analytics begin at activation; they cannot reconstruct earlier traffic reliably.
- Keep physical event attendance in `EVENT-ATTENDANCE-LOG.md`; website visits are not event attendance.

## Privacy and reporting

- Do not add a second analytics service unless the team approves the additional data collection.
- Report trends using an explicit date range and avoid implying that page views equal unique people.
- Keep any unpublished exports or internal reports outside the public website.
